# Валидация детектора на синтетических данных

Отчёт создаётся командой `node demo/validate.cjs`. Генератор детерминирован, поэтому при неизменном движке отчёт повторяется до символа. Порог тревоги CUSUM h = 10, seed — целое число от 1 до 999999.

## 1. Сценарии × seed 1…1000

| Сценарий | Обнаружено | Ложные | Повторы | Не закрыт | Задержка, с: мин / медиана / макс | Закрытие, с: медиана | CUSUM: медиана / макс | Порог: ложные / повторы |
|---|---|---|---|---|---|---|---|---|
| Полная демонстрация | 2000/2000 | 0 | 0 | 2/1000 | 9,5 / 14 / 17 | 11,5 | 111,22 / 120,82 | 1000 / 4796 |
| Одиночный выброс | 0/0 | 0 | 0 | 0/1000 | — | — | 2,49 / 9,23 | 1000 / 0 |
| Плавная деградация | 1000/1000 | 0 | 0 | 121/1000 | 14 / 23 / 26 | 18 | 127,6 / 139,27 | 0 / 3975 |
| Пропуск и поздняя пачка | 1000/1000 | 0 | 0 | 0/1000 | 6 / 6 / 6 | 2 | 2,13 / 7,55 | 1 / 0 |
| Допустимая смена режима | 0/0 | 0 | 0 | 0/1000 | — | — | 2,51 / 9,23 | 0 / 0 |

- Монитор находит все размеченные события и не даёт ни одной ложной тревоги или повтора.
- У простого порога в те же прогоны есть ложные срабатывания на выбросе и многократные повторы.
- Слабое место — закрытие. В «Плавной деградации» инцидент не успевает закрыться до конца записи у 121 из 1000 seed (12%). Правило требует пяти окон подряд с |z| < 1,35, и значения выше нормы тоже срывают серию. В отдельном эксперименте с односторонним правилом z < 1,35 незакрытых стало 18 из 1000, а ложных тревог и повторов по-прежнему не было. Это изменение поведения, в движок оно не внесено.

## 4. Длинные здоровые потоки

Ложные тревоги качества на потоках без неисправности, по 20 потоков по 1 ч (seed 1…20).

| Шум | Длительность | Ложных тревог | В час |
|---|---|---|---|
| Независимый гауссов (как в генераторе) | 20 ч | 0 | 0 |
| Тяжёлые хвосты: 5% выбросов ×3 | 20 ч | 0 | 0 |
| Автокорреляция AR(1), φ = 0,9 | 20 ч | 264 | 13,2 |

На независимом шуме ложных тревог нет. При автокорреляции детектор не годится: CUSUM считает соседние окна независимыми свидетельствами. Перед применением на реальных сенсорах нужно выбеливание остатков или калибровка порога по реальной записи.
