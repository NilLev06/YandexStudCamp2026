# Webots-дрон как источник для Sensor Watch

Mavic 2 Pro в Webots, управление наклоном телефона (Phyphox). Неисправности внедряет `faults.py` по сценарию,
контроллер о них не знает. Бортовой монитор (`monitor.py`) обнаруживает их и реагирует: компенсирует износ мотора,
сажает дрон при дрейфе гироскопа. Шлюз получает те же данные и показывает их оператору.

```
контроллер (Webots) --UDP 5006--> gateway_bridge.py --HTTP--> шлюз --> интерфейс
                                        |
                                        +--UDP 5016--> monitor.py (MONITOR_PORT=5016)
```

## Запуск (Windows)

```bat
:: 1. шлюз
cd gateway && uvicorn app.main:app --port 8000
:: 2. мост (в папке sim\webots_drone)
python gateway_bridge.py --gateway http://127.0.0.1:8000
:: 3. бортовой монитор на другом порту
set MONITOR_PORT=5016 && python monitor.py
:: 4. пульт с телефона
python bridge.py
:: 5. Webots: открыть worlds\drift.wbt, контроллер mavic_failsafe
```

Без моста `monitor.py` работает как раньше на порту 5006.

Без Webots можно проверить связку имитатором: `python tools/fake_drone.py --speed 2` (физики нет, только телеметрия и сценарий).

## Каналы в шлюзе

| Датчик | Значение | Деградация | Режимы |
|---|---|---|---|
| `mavic.gyro` | угловая скорость крена | в обе стороны | `hover` - оценивается, `maneuver` - только свежесть |
| `mavic.mag` | модуль магнитного поля | в обе стороны | `flight` (залипание не проверяется: в Webots компас без шума) |
| `mavic.vib` | модуль вибрации | вверх | `flight` |
| `mavic.motor1..4` | обороты измеренные / заданные | вниз | `flight`, `ground` - только свежесть |

Отсчёты сжимаются до 10 Гц (медиана за 0.1 с), окно монитора 1 с, свежесть 2 с. Эталоны режимов калибруются
автоматически по первым 50 отсчётам (σ не ниже паспортной точности канала).

Разметка сценария (`faults.py`) пересчитывается в настенное время по мере прохождения границ и загружается
отдельно: `mag_interference` -> mag/quality, `esc_dropout` -> motor1..4/availability, `vibration` -> vib/quality и noise,
`motor_wear` -> motor3/quality, `gyro_bias` -> gyro/quality. `esc_spike` - одиночный выброс: разметки нет, тревоги быть не должно.

На имитаторе (×2) шлюз находит помеху компаса, пропуск телеметрии ESC, вибрацию и износ мотора 3.
Дрейф гироскопа шлюз не успевает подтвердить: бортовой монитор сажает дрон раньше, а на земле гироскоп не оценивается.
Так и задумано: быстрая реакция на борту, наблюдаемость - в шлюзе.
