# SMD — серверные данные для испытаний

Выбран набор **Server Machine Dataset (SMD)**, опубликованный авторами OmniAnomaly:

https://github.com/NetManAIOps/OmniAnomaly/tree/master/ServerMachineDataset

Версия источника: `7fb0e0acf89ea49908896bcc9f9e80fcfff6baf4`.

## Первичная выборка

Для первого сквозного эксперимента выбрана машина `machine-1-1`. Исходные файлы размещаются локально в `raw/` и исключены из Git. Проверенные размеры, контрольные суммы, число точек и интервалы аномалий записываются в `manifest.json` после завершения загрузки и проверки.

Загрузка и проверка выполнены 26 октября 2026 года: 28 479 обучающих и 28 479 тестовых строк, 38 каналов, 2694 аномальных тестовых строки (около 9,46%), 8 непрерывных интервалов метки 1. Среди интервалов есть очень короткие — длиной 2–3 отсчёта. Значения в обоих скачанных массивах лежат в диапазоне [0, 1]; это опубликованные обработанные данные, не исходные физические единицы.

Контрольные суммы всех четырёх файлов проверены. Сохранена исходная MIT License (`Copyright (c) 2021 NetManAIOps-SMD`).

| Каталог | Содержание |
|---|---|
| `train/` | Первая часть ряда, 38 числовых каналов |
| `test/` | Вторая часть ряда, те же 38 каналов |
| `test_label/` | Метка 0/1 для каждой строки тестовой части |
| `interpretation_label/` | Каналы, связанные с размеченными аномалиями |

## Протокол использования

1. Разделить `train` хронологически на участок оценки нормы и участок настройки порогов. Не перемешивать точки случайным образом.
2. Фиксировать параметры до оценки на `test`. Тестовые метки подавать только оценщику, не детектору и не процедуре настройки.
3. В опубликованных числовых матрицах нет столбца временных отметок. До независимого подтверждения частоты ось времени и задержку выражать в отсчётах. Искусственное воспроизведение с заданной скоростью не является исходным временем измерения.
4. Каналы обозначать `metric_01`…`metric_38`, пока не подтверждено соответствие физическим метрикам. Не выдумывать названия CPU, память или пользователи для конкретных столбцов.
5. Заданные в демонстрации эталоны 95/80 и σ=1,5 для этих данных не подходят. Норму нужно оценивать отдельно по каждому каналу.
6. Разметка тестовой строки описывает аномалию многомерного наблюдения. Не требовать от каждого из 38 каналов одинаковой реакции; отдельно учитывать вспомогательную разметку каналов.
7. После проверки конвейера расширить выборку на другие машины из трёх групп. Результаты показывать отдельно по машинам и в сводном виде.

Исходный репозиторий содержит файл `ServerMachineDataset/LICENSE`; при распространении данных сохранять исходную лицензию и атрибуцию.

Замечание по разметке: границы `interpretation_label` не полностью совпадают с непрерывными интервалами `test_label`. Например, первый записан как `15849-16368`, а первый непрерывный интервал единиц `test_label` при индексации с нуля — `15849…16394`. До выяснения соглашений основную оценку событий строить по `test_label`; вспомогательную разметку не считать точной заменой границ событий. В `manifest.json` все индексы явно нулевые, конец включён.

На этом этапе набор подготавливается отдельно: существующая веб-демонстрация остаётся на синтетике.
